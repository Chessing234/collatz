# arxiv-1010-3692-a-collatz-type-conjecture-on-the-set-of-rational-number

Citation: Mohammad Javaheri, "A Collatz-type conjecture on the set of rational numbers", arXiv:1010.3692 [2010].

Authors: Mohammad Javaheri

arXiv: [1010.3692](https://arxiv.org/abs/1010.3692)

Year: 2010

Classification: density

Abstract:

Define $θ(x)=(x-1)/3$ if $x\geq 1$, and $θ(x)=2x/(1-x)$ if $x<1$. We conjecture that the orbit of every positive rational number ends in 0. In particular, there does not exist any positive rational fixed point for a map in the semigroup $Ω$ generated by the maps $3x+1$ and $x/(x+2)$. In this paper, we prove that the asymptotic density of the set of elements in $Ω$ that have rational fixed points is zero.
